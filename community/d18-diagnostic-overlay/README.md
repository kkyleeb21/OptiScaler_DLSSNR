# Diagnostic source overlay

The release core uses the main OptiScaler source tree (tested C9). The diagnostic core uses that tree with these four C10/C11 files overlaid, built with `/p:D18DiagnosticBuild=1`. Apply this overlay to a separate source checkout, not the release checkout. The manifest records both original and replacement hashes. These changes permit explicitly enabled, bounded unknown-game input observations and focused shader identities; they do not implement automatic SR/FG compatibility. No markers or game-specific focus lists are installed by the distributed package.

Both profiles retain experimental shared history. Pixel capture and model bypass require the diagnostic profile and explicit opt-in. Rendering defaults remain off. Executable embedded candidate labels are retained from the exact tested/recorded binaries; package VERSION and SOURCE_PROVENANCE identify 0.1.8.
