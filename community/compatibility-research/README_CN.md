# 兼容性研究（独立章节）

本章节独立于 0.1.8 发布收口。未知游戏自动 SR/FG override 尚未实现，不构成本版支持承诺。

1. 复用标准 DLSS/FSR/XeSS 输入及共享后端，按接口/引擎路径归类。
2. 无标准输入游戏：自动发现颜色、深度、运动矢量和候选交接点，区分候选、已验证语义与可用渲染路径。
3. 验证通过的输入适配复用共享格式转换、资源寿命、同步和失败回退；不靠游戏名强行解锁模型功能。
4. 蝙蝠侠停在观察研究阶段：首轮绑定与本地 shader 缓存提供候选，C11 可做定向身份观察；尚未实现 SR/FG，当前不要求继续补采。
5. 后续依据收益与成本安排，单独验收。共享历史、多 API 画质与输入识别分别归因，不因菜单或 API 成功宣布兼容。

诊断使用 tools/D18 统一入口；不随公开源码分发游戏 shader、个人配置或采样像素。已有本地证据与回滚备份保留。
