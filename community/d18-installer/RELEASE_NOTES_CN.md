# D18 0.3.0

- 全新游戏内菜单：固定顶部与底部、页签导航，状态与诊断改为独立窗口。默认黑白配色，也可选其他配色；支持 HDR 菜单亮度、高对比度文字、文字大小与保存状态提示。
- 新安装器：单个 `D18Setup.exe`，提供游戏列表，同一程序负责安装和卸载；黑白界面，跟随 Windows 的亮 / 暗设置。主包精简，FSR / XeSS 改为单独的可选组件包。
- 游戏不提供曝光时，可估算 NR 白点。目前默认只对 007 First Light 开启；其他游戏可在“高级 → 曝光与 HDR 输入”手动开启。仅支持 DX12，属于实验性功能。Paper white 下限放宽到 0.01。

升级保留现有配置。之前用 D18 提供 FSR / XeSS 的用户，升级时需要勾选可选组件；安装器会从本次发布页下载，也可以指定自己下载好的可选组件 ZIP。新装 NR 总开关默认关闭。

已知问题：安装器未签名，Windows 可能提示来源未知。鬼武者使用轮询输入，刚进游戏就打开菜单时，滑块可能拖不动、鼠标可能转动视角；关闭并重新打开菜单即可。
