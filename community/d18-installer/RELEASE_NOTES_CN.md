# D18 0.1.8

## 0.1.8 修订 1（R1）

- 统一安装检查器与 DX11 原生后端的 NR 补丁位置校验，移除后端遗留的无关代码区 SHA 白名单；保留补丁冲突与必要 ABI 检查。用户原始 NR 不修改、不删除；通过检查不代表任意运行库或游戏已验证兼容。
- 公共诊断采集支持用户自选输出目录，默认使用本地应用数据下唯一目录；不覆盖旧证据、不修改游戏配置。归并旧采集入口及各 API 摘要。
- 公开下载仅保留 release。诊断版留作内部排查，不再提供公共 diagnostic 包；常规 Summary 仍按需可用、默认关闭且有界。共享历史仍可选，实验性且可能闪烁。
- 公共包移除历史内部部署、清理、构建与 GPU 实验入口；工程源码中保留研究工具。渲染核心和 GUI 启动器沿用 0.1.8，原生 addon / 检查器同步重建。

已安装原版 0.1.8 的用户：退出游戏后用本修订安装器更新，保留用户配置和原始 NR。包内 REVISION.txt 为 1，对应源码标签 dlssnr-d18-v0.1.8-r1；旧标签保留原始发布身份。

基于 0.1.7 的累计更新，加入高分辨率单遍、1–4 遍 NR、逐遍模型参数和新的分栏界面，完善原生 DX11 接入、格式兼容和安装依赖准备。保留完整 SR 基底，各遍比例按完整 SR 尺寸计算，模型结果连续传递，最后仅合成一次。

## 渲染与界面

- DX12 及已有有效输入交接的原生 DX11/Vulkan NR 路径支持独立多遍、逐遍参数和高分辨率单遍（1.25× / 1.5×，尺寸有对齐）。这不会自动为任意没有超分入口的游戏补出 SR/FG 输入。
- 神经渲染、SR、FG、锐化、调试分栏；总览保留状态、实时诊断、快捷键和原图对比。模型设置集中管理模式、遍数、历史与逐遍参数。
- 多遍/高分辨率支持的格式依据资源与设备读写能力检查，保留原格式 SR 基底，模型中间图使用私有 FP16。部分尺寸/格式准入失败可通过切回普通模式重试；设备丢失可能仍需重启。
- 最终高频保护可用于 DX12 各 NR 模式，以及原生 DX11/Vulkan 的多遍和高分辨率最终合成；不额外增加模型调用。原生后端普通单遍保留原有行为。
- 原生 SR 的启用与画质设置保存/恢复、FG 请求与状态处理得到修正。原生 DX11 首次选择插件 FG 路径后需保存并重启一次准备呈现，此后可在游戏内开关；首次运行中将普通交换链替换为 FG 交换链尚未实现。保留 FG 路径会有互操作开销，选择无 FG 并重启可释放。

## 安装与默认设置

- 公开提供完整 release 安装包；diagnostic 构建留作内部像素捕获、模型旁路与输入观察排查。常规诊断默认关闭且有界，工具统一归入 tools/D18。
- 全新安装默认关闭 D18 NR、原生 SR 接入、插件 FG、锐化覆盖、对比和诊断；高分辨率、多遍、共享历史不自动启用。升级保留用户已有设置，不会关闭游戏自身的 SR/FG。
- 依赖页可检查并准备缺失的 SR、插件 FG 配套文件、适用的 REFramework 和 VC++ x64。已有文件默认保留；NR 文件由用户自行提供。NVIDIA SR/FG/NR 运行库不随包分发。
- 成功安装且哈希复核后，完成页默认清理本次会话拥有的缓存，可取消。失败、占用、变化文件保留；用户原始 NR、其他会话缓存及回滚备份不删除。
- API 由用户按游戏实际启动方式选择；切换 API 后重新运行安装器选择对应 API。异环 Steam 版在实际 HTGame.exe 目录安装，代理选择 `version.dll`。
- 检测到反作弊时，安装器提示并由用户确认后继续，不直接禁止安装；确认不代表反作弊兼容或账号安全保证。

## 已知限制

- 共享历史在两种构建中均可选择，默认关闭且属实验功能：可能闪烁、出现分块明暗变化或运动不稳定，建议优先独立历史。各遍参数需一致；不一致时 DX12 保留单遍，原生 DX11/Vulkan 保留 SR 原图并显示失败状态。
- 多遍会增加 GPU 时间和显存需求，可能强化轮廓、局部对比及材质/光照效果，使皮肤明暗过渡变硬、肤色加深或偏黄/橙/红。独立历史也可能如此；更多遍不代表更好画质，建议从单遍或双遍开始，按需降低模型或最终合成强度。
- 高频保护保留细小纹理，不保证修正模型重绘、肤色偏移或明暗色块。高分辨率单遍也可能改变风格，其画质收益不保证，开销增加；观感变差时可切回普通单遍。
- FG 的可用性、HUD 分离、运动表现及高倍率效果依赖实际输入和呈现路径；DX11 可能出现拖影、变形或错位。Vulkan FG 仍属实验功能。原生 DX11 多遍目前逐遍等待完成；Vulkan 高级 NR 暂不提供像素 Capture。
- 对没有标准超分输入的游戏，自动识别颜色/深度/运动矢量并接入 SR/FG 尚未实现。兼容性研究单独推进，不将 API 成功或菜单可打开视为画质与全游戏兼容保证。
