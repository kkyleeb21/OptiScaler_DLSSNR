# D18 0.4.1

这是修正版，功能与 0.4.0 相同。使用了 0.4.0 新增的调色、压暗下限或暂停 NR 功能的用户，建议更新。

- **调色：**更新调色与 NR 执行不再可能交错。内存保护还原失败时会持续重试，并如实显示状态。局部色调较低时，无法应用的白点 / 黑点组合会提示而不是写入；局部色调低于 0.05 时不应用调色。
- **暂停 NR：**检测到多个帧生成视口时，会自动停用该功能并提示。旧实验配置键不再覆盖新的开关。
- **V8 模式：**菜单显示实际生效的提亮上限 / 压暗下限。
- **安装器：**拒绝安装到盘符根目录、系统目录、用户文件夹本身，或顶层没有 EXE 的目录，并给出原因；已有安装的卸载不受影响。

更新时在同一游戏目录使用“升级”，现有配置会保留。已知问题沿用下方说明；原生 DX11 暂不支持调色和单独的压暗下限。

# D18 0.4.0

- **调色**：基础页“调色”栏位。NR 的三种风格除了模型本身的差别，还各自带一套曝光 / 对比 / 饱和度调整；现在可以关掉它或换成自己的曝光、对比、饱和度，以及“更多”里的黑白点、伽马、色偏和分段色调曲线。可与任意风格组合，三个预设栏位可保存“风格 + 调色”；需要 NR 运行库 310.8，支持 DX12 / Vulkan。
- **提亮上限 / 压暗下限**：高级 → 合成。原“高光保护”拆成两项，可以单独限制 NR 把画面压暗的程度，例如减轻人物被压暗，而不影响它提亮的部分。压暗限制在合成中会作用两次，实际最暗值可能低于所示百分比。
- **游戏关闭帧生成时暂停 NR**：高级页。部分游戏在菜单、对话或过场时会关闭自带的 DLSS 帧生成并解除帧率上限，此时 NR 按真实帧率全速运行，功耗明显升高。开启后，这些时段暂停 NR，帧生成恢复时自动继续；只对使用游戏自带 DLSS 帧生成的 DX12 游戏有效。

三项默认关闭，不开启时行为与 0.3.1 相同。隔帧 NR 等实验内容没有进入本版。更新时在同一游戏目录使用“升级”，现有配置会保留。

已知问题沿用下方 0.3.1 / 0.3.0 说明；原生 DX11 游戏暂不支持调色和单独的压暗下限。

# D18 0.3.1

- 安装器的游戏列表现在一个游戏只显示一项，显示游戏名；不再列出崩溃上报、运行库工具、设定集等非游戏程序。
- 电脑上装了 NVIDIA App 时，优先使用它的游戏列表，再加上 Steam / Epic / GOG / EA 的安装记录。没有列出的游戏仍可手动添加或拖入。
- 核心功能与 0.3.0 相同；已在用 0.3.0 的用户不必为游戏内功能升级。更新时保留现有配置，已知问题沿用 0.3.0。

# D18 0.3.0

- 全新游戏内菜单：固定顶部与底部、页签导航，状态与诊断改为独立窗口。默认黑白配色，也可选其他配色；支持 HDR 菜单亮度、高对比度文字、文字大小与保存状态提示。
- 新安装器：单个 `D18Setup.exe`，提供游戏列表，同一程序负责安装和卸载；黑白界面，跟随 Windows 的亮 / 暗设置。主包精简，FSR / XeSS 改为单独的可选组件包。
- 游戏不提供曝光时，可估算 NR 白点。目前默认只对 007 First Light 开启；其他游戏可在“高级 → 曝光与 HDR 输入”手动开启。仅支持 DX12，属于实验性功能。Paper white 下限放宽到 0.01。

升级保留现有配置。之前用 D18 提供 FSR / XeSS 的用户，升级时需要勾选可选组件；安装器会从本次发布页下载，也可以指定自己下载好的可选组件 ZIP。新装 NR 总开关默认关闭。

已知问题：安装器未签名，Windows 可能提示来源未知。鬼武者使用轮询输入，刚进游戏就打开菜单时，滑块可能拖不动、鼠标可能转动视角；关闭并重新打开菜单即可。
