# D18 0.1.9 — SH0 锐化与实验性 V8 引导重建

- 在“锐化”页加入 **D18 锐化（SH0）**，与 OptiScaler 锐化明确区分。保留 Original/Overlapping、Separated、全/半分辨率模糊及独立中频/细节强度。默认关闭，切换不触发 NR feature 重建；位于 NR 合成之后、帧生成及 UI 之前。
- 保留现有合成路径，增加可选 **R0 对照 / 实验性 V8**。V8 用完整 SR 引导模型输出亮度重建。本版限定：3840×2160 SR、50% NR、标准单遍、LINEAR 模型颜色输入、POINT 输出、自定义预滤波关闭；支持 DX12 R11/FP16 与 Vulkan FP16。DX11 没有 V8。不支持的组合及 100% NR 沿用原路径，选择选项不等于实际生效。
- V8 默认关闭，启用后增加 GPU 工作内存（每组约 633 MiB；DX12 在途工作最多保留三组）。性能和画质收益随场景变化，不能还原 runtime 的 100% 色彩与打光编辑。SH0 可能强化锯齿；本版未加入新的防振铃限幅或结构锐化门。
- 保留 0.1.8 R1 安装器、原始 runtime/配置保护与统一补丁位置检查。核心、原生后端、检查器同步重建为 0.1.9。公开 release 禁用内部捕获、模型旁路及研究控制；保留默认关闭、有界的常规诊断和可独立使用的 SH0/V8 日志摘要。

**更新：**退出游戏，完整解压 ZIP，运行 `D18Install.exe`。升级保留现有设置，新安装的渲染与可选处理开关全部关闭，包括 PHF、预滤波、内部缩放、曝光输入和皮肤掩码。不包含 NVIDIA NR/SR/FG 运行库，NR 需在安装器中自行提供兼容文件。公开仅分发 release 包。

**既有限制保留：**共享历史实验性且可能闪烁；多遍/高分辨率增加开销，不保证画质更好。API、输入及 FG 兼容性取决于实际路径，菜单或 API 成功不能证明实机兼容。保留不同合成与锐化选项用于比较。

源码标签：`dlssnr-d18-v0.1.9`。SHA256SUMS.txt 对应本次唯一发布 ZIP。
